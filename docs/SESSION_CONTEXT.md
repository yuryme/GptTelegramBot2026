## Диагностика production-бота

- Ошибка кнопки `Показать напоминания на сегодня` была воспроизведена по журналу VPS.
- Причина на момент сбоя: DeepSeek ответил `401 Unauthorized` из-за недействительного API-ключа.
- Пользователь позднее сообщил, что ключи заменены и бот снова работает.
- Фиксированная кнопка списка сейчас проходит через LLM, поэтому недоступность DeepSeek ломает даже этот простой сценарий.
- Это диагностическое наблюдение; отдельное изменение deterministic handler не согласовано и не реализовано.

## Google Sheets и Apps Script

- Решено использовать Google-аккаунт пользователя как владельца таблицы и Apps Script.
- Приятелю можно предоставить доступ к таблице как читателю или редактору; его пароль Google не нужен.
- PostgreSQL остается основным хранилищем, чтобы заявки не терялись при недоступности Google.
- Apps Script должен принимать JSON по HTTPS, проверять общий секрет из Script Properties и добавлять либо обновлять строку по `delivery_id`.
- Рекомендуемые Script Properties: `SPREADSHEET_ID`, `SHEET_NAME`, `WEBHOOK_SECRET`.
- Web App разворачивается с `Execute as: Me` и доступом для вызова без интерактивного Google login.
- Пользователь дошел до экрана OAuth с предупреждением `Google hasn't verified this app`; для собственного скрипта было объяснено продолжение через `Advanced` после проверки аккаунта и прав.
- Не подтверждено, что deployment завершен и URL `/exec` получен.
- Webhook URL и secret должны храниться только в серверном `.env`, не в Git и не в этом файле.

## Gmail SMTP

- Решено отправлять письма из Google/Gmail-аккаунта пользователя.
- Получатели будут видеть Gmail-адрес пользователя; `Reply-To` можно направить приятелю.
- Пользователь открыл страницу Google App Passwords и получил возможность создать пароль с произвольным названием, например `Telegram Materials Bot`.
- Не подтверждено, что App Password уже создан и сохранен на VPS.
- App Password показывается Google один раз и затем хранится только в защищенном серверном `.env`.
- Предполагаемые настройки: `smtp.gmail.com`, порт `587`, STARTTLS.
- Код проекта пока не читает SMTP-переменные и не отправляет письма.
